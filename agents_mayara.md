# AGENTS.md

## Visão geral

O objetivo desse projeto é criar uma aplicação que apresente um dos meus interesses, sendo esse a banda sueca GHOST, auxiliando que pessoas aprendam mais sobre mim e possam interagir comigo sobre esse interesse, e o publico alvo são meus colegas e professores da faculdade.

## Tecnologias

Nesse projeto deve ser usado HTML para estruturação da aplicação web, com estilização em CSS e funcionalidade em JavaScript, utilizando a API web-data-viz se conectando ao MySQL na database "cadastro_pessoal".

## Comandos

Criar uma aplicação web seguindo o uso das tecnologias mencionadas anteriormente, conecte a API com o banco de dados especificado e permita a insercao de dados capturados pela pagina web por meio do web-data-viz, sem alterar radicalmente a estrutura ja feita e o codigo legado.
Crie um usuario com privilegios para realizar INSERT no banco de dados e crie as tabelas necessarias relacionadas com o tema segundo o prompt.

## Arquitetura

Criar arquivos somente dentro do repositorio 'projeto_pessoal' e caso seja necessario crie repositorios dentro dele de acordo com a necessidade. A subpasta 'imagens' deve ser utilizada para popular o site visualmente, dando a ele mais personalidade e identidade visual, porem o esquema de cores/identidade visual deve ser seguido a risca. O diretorio 'imagem' depende do diretorio-pai 'projeto_pessoal'.

## Padrões de desenvolvimento

- Utilizar let apensas quando houver necessidade de reatribuicao
- Por padrao os arquivos terao nomes faceis de localizar. Exemplo: arquivo da pagina princial teria o nome de index.
- Por padrao as funcoes devem ter nomes simples de identificar e localizar.
- As variaveis por padrao devem ter nome de verbos.

## Cuidados e restrições

- O agente nao deve alterar o codigo legado de forma radical sem antes confirmar se alguma alteracao pode ou deve ser feita.

## Regra geral: 
Antes de implementar uma alteração, siga as tecnologias, arquitetura, convenções e restrições descritas neste documento. Caso alguma informação esteja ausente, analise o código existente e siga os padrões já adotados no projeto.
